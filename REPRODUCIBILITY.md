# Reproducing the Figure 7 equity analysis

This guide covers the **current revised-equal-area Figure 7**, which runs
from small derived inputs already tracked in this repository. It does not
rebuild the external land-cover, UCM or health rasters; follow the
[full workflow map](docs/WORKFLOW.md) for those upstream stages.

## Prepare R

Clone the repository and work from its root. Install R and the packages used
by the production script if they are not already present:

```bash
git clone https://github.com/natcap/urban-cooling-health.git
cd urban-cooling-health
```

```r
install.packages(c(
  "biscale", "cowplot", "digest", "dplyr", "ggplot2", "knitr", "purrr",
  "ragg", "readr", "rmarkdown", "scales", "sf", "tidyr"
))
```

`sf` and `ragg` may require system geospatial and graphics libraries. The
[saved session information](figures/equity_map_biscale_revised_equal_area/fig7_session_info.txt)
records the last validated R package versions; a project-wide R lockfile is
still an [open task](TODO.md).

## Interpretation held constant across the project

All health analyses apply 2050 temperature fields to 2021 population and 2021
baseline mortality. This isolates land-cover and climate effects. It is not a
forecast of London's demographic composition in 2050.

## Run Figure 7

From the repository root, run the production wrapper. It does not require Pandoc:

```bash
Rscript code/run-fig7.R
```

By default, outputs go to
`figures/equity_map_biscale_revised_equal_area/`. For a non-destructive test
run, set `URBAN_COOLING_FIG7_OUTPUT_DIR` to a new folder, for example:

```bash
URBAN_COOLING_FIG7_OUTPUT_DIR=./figures/fig7_local_check Rscript code/run-fig7.R
```

To create the accompanying HTML notebook when Pandoc is available, run:

```r
rmarkdown::render(
  "code/equity-health-fig7-production.Rmd",
  knit_root_dir = normalizePath(".")
)
```

The workflow checks official-code and scenario pairing, duplicate IDs, missing
benefit values and population join coverage. It writes to
`figures/equity_map_biscale_revised_equal_area/`:

- `fig7_ab_upgraded.png` and `fig7_cd_upgraded.png` (plus PDF/SVG): the maps
  and paired comparison panels;
- `fig7_quantitative_headline_results.csv`, `fig7_paired_transition_matrix.csv`
  and `fig7_citywide_tradeoff.csv`: the main numerical evidence;
- `fig7_age75_*.csv` and `fig7_citywide_uncertainty.csv`: diagnostics and
  paired-draw uncertainty;
- `fig7_run_metadata.csv` and `fig7_session_info.txt`: analysis settings and
  R environment; and
- `fig7_file_manifest.csv`: SHA-256 checksums for inputs/outputs of that run.

The manifest is generated by a fresh run; it is not part of the currently
tracked historical output snapshot.

Inspect the figures and source tables before using any number in a manuscript.

## Verify equal intervention budgets

The tracked-input Figure 7 run above does not require external rasters. For a
full scenario rebuild, run the **current six-scenario validator** on the
versioned baseline and Green/Target LULC rasters before accepting the figure:

```bash
python code/lc_scenarios/validate_green_target_scenarios.py \
  --baseline /path/to/baseline_lulc.tif \
  --green /path/to/green10.tif /path/to/green20.tif /path/to/green30.tif \
  --target /path/to/target10.tif /path/to/target20.tif /path/to/target30.tif \
  --output-json /path/to/versioned-output/green_target_pair_qa.json \
  --output-csv /path/to/versioned-output/green_target_pair_qa.csv
```

The validator checks grid and NoData identity, eligible transitions, nesting
and exactly equal added-canopy cells at each tier. Retain its JSON/CSV and
checksums in the versioned external run folder; see the
[scenario guide](code/lc_scenarios/README.md) for the scientific definition.
The earlier `validate_scenario_canopy_budget.py` is a historical, narrower
code-100 audit and is not the release gate for the revised comparison.

## Final review checklist

1. Confirm 4,835 paired LSOAs and complete 2021 population coverage.
2. Confirm Green30 thresholds are used for both scenarios and all maps.
3. Confirm the canopy-budget validation passes.
4. Confirm both model runs used seed `20260908` and 2,000 paired draws.
5. Inspect both exported PNGs at full size for clipped labels and legends.
6. Quote the fixed-2021-population assumption in Methods and figure captions.
7. Confirm `fig7_file_manifest.csv` matches the files supplied with the
   manuscript.

Figure 6 is not reproduced by this workflow. Its unresolved estimand and
spatial-inference decisions are listed in
`code/health_assessment/FIGURES6_7_REVIEW.md`.
